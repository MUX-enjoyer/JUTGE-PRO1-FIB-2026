I.Cerca dicotòmica

Imaginem-nos un vector de nombres ordenat creixentment i la pregunta: «hi és, el valor x?». La cerca lineal recorreria tots els elements un a un, en el pitjor cas. La cerca dicotòmica, en canvi, aprofita l'ordre per descartar la meitat dels candidats a cada pas.

La idea

Mantenim dos índexs, esq (esquerra) i dre (dreta), que delimiten la zona del vector on encara pot ser-hi x. Mirem l'element del mig, mig = (esq+dre)/2, i:

  • si v[mig] == x, l'hem trobat.
  • si v[mig] < x, com que el vector és ordenat, x (si hi és) ha de ser a la dreta de mig → recursió amb esq = mig+1.
  • si v[mig] > x, ha de ser a l'esquerra → recursió amb dre = mig-1.

El procés acaba quan trobem l'element o quan esq > dre (la zona ha quedat buida).

Codi en C++

Implementació recursiva: retorna la posició si el trobem, o -1 si no hi és.

C++
// Pre: v[esq..dre] està ordenat creixentment // Post: retorna una posició i tal que v[i] == x, // o -1 si x no apareix a v[esq..dre] int posicio(double x, const vector<double>& v, int esq, int dre) { // Si l'interval és buit, retornem -1 if (esq > dre) return -1; int mig = (esq + dre) / 2; if (v[mig] == x) return mig; else if (v[mig] < x) { return posicio(x, v, mig+1, dre); } else if (v[mig] > x) { return posicio(x, v, esq, mig-1); } // Si no hem trobat el valor, retornem -1 return -1; }
Atenció La implementació és recursiva: cada crida s'encarrega de l'interval [esq..dre]. El cas base és quan esq > dre (interval buit) i retornem -1. A cada pas recursiu l'interval es divideix per dos, garantint la terminació.

Cost

A cada crida recursiva la zona candidata es divideix per dos. Si partim de n elements, després de k crides en queden com a molt n/2k. La cerca s'atura quan en queda menys d'un, és a dir, quan k ≈ log₂ n.

El cost en el pitjor cas és Θ(log n). Per a un vector de mil milions d'elements, només calen unes 30 comparacions.

II.Inserció en un vector ordenat

Suposem que tenim un vector ordenat i hi volem afegir un nou valor x mantenint la propietat d'estar ordenat. No n'hi ha prou amb posar-lo al final: cal trobar-li el lloc correcte i, abans, fer-li espai desplaçant els elements més grans una posició a la dreta.

Dues fases

L'algorisme recorre el vector de dreta a esquerra i fa les dues coses alhora:

  1. Mentre l'element actual sigui més gran que x, el copiem una posició a la dreta.
  2. Quan trobem un element ≤ x (o arribem al començament), el forat resultant és exactament on ha d'anar x.

Codi en C++

El vector rep el nou element ja afegit al final; la funció el col·loca a la seva posició correcta.

C++
// Pre: v[0..n-2] està ordenat creixentment; v[n-1] és el nou element // Post: v[0..n-1] està ordenat creixentment i conté // els mateixos elements que abans més l'últim valor original #include <iostream> #include <vector> using namespace std; void insereix(vector<double>& v) { int n = v.size(); if (n < 2) return; // Si el vector té 0 o 1 elements, ja està "ordenat" double x = v[n - 1]; // Agafem l'últim element int j = n - 2; // Comencem a comparar des del penúltim element // Desplacem els elements més grans que x cap a la dreta while (j >= 0 && v[j] > x) { v[j + 1] = v[j]; // Desplacem l'element a la dreta --j; } // Col·loquem x a la seva posició correcta v[j + 1] = x; } int main() { cout.setf(ios::fixed, ios::floatfield); cout.precision(4); int n; while (cin >> n) { vector<double> V(n); for (int i = 0; i < n; ++i) { cin >> V[i]; } insereix(V); for (int i = 0; i < n; ++i) { cout << " " << V[i]; } cout << endl; } return 0; }
Observació Fixeu-vos que no hem fet una cerca dicotòmica per trobar la posició. Tot i que sabríem on va x en temps Θ(log n), igualment hauríem de desplaçar fins a n elements; el cost dominant és el desplaçament, no la cerca. Per això és més senzill fer-ho tot en un sol bucle.

Cost

En el pitjor cas — quan x és més petit que tots els elements del vector — cal desplaçar-los tots. El cost és Θ(n).

En el millor cas — quan x és més gran o igual que l'últim element — el bucle no s'executa cap vegada i el cost és Θ(1).

III.Ordenació per inserció

Ja tenim el procediment per inserir un element en un vector ordenat. Què passaria si l'apliquéssim repetidament? Si comencem amb un vector ordenat de zero elements i hi anem afegint, un a un, tots els valors d'un vector desordenat... obtenim un mètode d'ordenació.

La invariant

Recorrem el vector d'esquerra a dreta amb un índex i. En tot moment, garantim aquesta propietat:

Invariant del bucle Just abans de processar la posició i, el subvector v[0..i-1] està ordenat (conté els mateixos elements que tenia al principi, però ordenats), i v[i..n-1] encara no s'ha tocat.

A cada iteració agafem v[i] (l'anomenem la clau) i la inserim al lloc correcte dins de v[0..i-1], fent servir exactament la mateixa tècnica del capítol anterior. Després, la zona ordenada creix fins a v[0..i], i avancem.

Codi en C++

Comparem-ho amb la inserció de la secció anterior: gairebé és la mateixa estructura, però dins d'un bucle extern sobre i.

C++
// Pre: v té n elements // Post: v està ordenat creixentment #include <iostream> #include <vector> using namespace std; void ordena_per_insercio(vector<double>& v) { int n = v.size(); // Per cada element a partir del segon (i = 1) for (int i = 1; i < n; ++i) { double x = v[i]; // L'inserim a la part ordenada (a l'esquerra) int j = i - 1; // Mentre no arribem al principi (j >= 0) // i l'element de l'esquerra sigui més gran que x while (j >= 0 && v[j] > x) { v[j + 1] = v[j]; // Desplacem --j; } // Posem l'element a la seva posició correcta v[j + 1] = x; } } int main() { cout.setf(ios::fixed, ios::floatfield); cout.precision(4); int n; while (cin >> n) { vector<double> V(n); for (int i = 0; i < n; ++i) { cin >> V[i]; } ordena_per_insercio(V); for (int i = 0; i < n; ++i) { cout << " " << V[i]; } cout << endl; } return 0; }
C++
// Variant amb intercanvis: més senzilla però una mica // menys eficient, perquè cada swap fa 3 assignacions void ordena_per_insercio(vector<double>& v) { int n = v.size(); for (int i = 1; i < n; ++i) { int j = i; while (j > 0 && v[j - 1] > v[j]) { swap(v[j - 1], v[j]); --j; } } }

Per què comença a i = 1?

Un vector d'un sol element ja està ordenat trivialment, així que el subvector v[0..0] compleix la invariant abans de la primera iteració. La feina comença a la posició 1.

Cost

Cada inserció parcial costa Θ(i) en el pitjor cas. Sumant per a totes les i entre 1 i n-1:

1 + 2 + 3 + ··· + (n−1) = n(n−1)/2 ∈ Θ(n²)

En el millor cas — vector ja ordenat — el bucle intern no s'executa cap vegada i el cost total és Θ(n). Aquesta és una propietat interessant: l'ordenació per inserció és adaptativa, és a dir, va més de pressa com més ordenat estigui ja el vector.

IV.Diferència de taules

Donats dos vectors ordenats creixentment v1 i v2, volem obtenir un tercer vector que contingui tots els elements de v1 que no apareixen a v2, mantenint l'ordre. Aquesta operació és anàloga a la diferència de conjunts: v1 \ v2.

L'estratègia de dos punters

Aprofitem que tots dos vectors estan ordenats. Mantenim un índex i per a v1 i un índex j per a v2, i els avancem coordinadament:

  • Si v1[i] < v2[j]: com que v2 és creixent, v1[i] no pot aparèixer a v2 → l'afegim al resultat i avancem i.
  • Si v1[i] == v2[j]: v1[i] sí apareix a v2 → el saltem (no l'afegim) i avancem i.
  • Si v1[i] > v2[j]: v2[j] és massa petit per coincidir; pot ser que un element posterior de v2 sí coincideixi → avancem j.
  • Si j ha arribat al final de v2: qualsevol element restant de v1 va directament al resultat.

Codi en C++

C++
// Pre: v1 i v2 estan ordenats creixentment // Post: retorna un vector ordenat amb els elements de v1 // que no apareixen a v2 (v1 \ v2) #include <iostream> #include <vector> using namespace std; vector<double> diferencia(const vector<double>& v1, const vector<double>& v2) { vector<double> resultat; int i = 0; // Punter per a v1 int j = 0; // Punter per a v2 while (i < v1.size()) { // Si v2 s'ha acabat, qualsevol element nou de v1 va al resultat if (j == v2.size()) { resultat.push_back(v1[i]); i++; } // Si v1[i] < v2[j], no pot estar a v2 → l'afegim i avancem i else if (v1[i] < v2[j]) { resultat.push_back(v1[i]); i++; } // Si són iguals, l'ignorem i avancem i else if (v1[i] == v2[j]) { i++; } // Si v1[i] > v2[j], avancem j per buscar el possible igual else { // v1[i] > v2[j] j++; } } return resultat; } int main() { cout.setf(ios::fixed, ios::floatfield); cout.precision(4); int n1; while (cin >> n1) { vector<double> V1(n1); for (int i = 0; i < n1; ++i) cin >> V1[i]; int n2; cin >> n2; vector<double> V2(n2); for (int i = 0; i < n2; ++i) cin >> V2[i]; vector<double> res = diferencia(V1, V2); int n3 = res.size(); cout << n3 << endl; for (int i = 0; i < n3; ++i) cout << " " << res[i]; cout << endl << endl; } return 0; }
Eficiència clau Cada índex (i i j) avança únicament cap endavant i mai retrocedeix. Per tant, el bucle fa com a molt |v1| + |v2| iteracions. El cost total és Θ(|v1| + |v2|), molt millor que la cerca lineal per a cada element de v1, que costaria Θ(|v1| · |v2|).

Cost

En el pitjor cas, quan cap element de v1 no apareix a v2 (o v2 és buit), recorrem v1 sencer. En el millor cas, quan v2 conté tots els elements de v1, avancem tots dos punters simultàniament. En ambdós casos el cost és Θ(|v1| + |v2|).

Els quatre algorismes formen una cadena natural: cada un assumeix la propietat que l'anterior ajuda a construir o explotar. La cerca aprofita l'ordre, la inserció el preserva, l'ordenació per inserció el construeix aplicant la inserció repetidament, i la diferència el combina coordinant dos punters sobre dos vectors ja ordenats.
